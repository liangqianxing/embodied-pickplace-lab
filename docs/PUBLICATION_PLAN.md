- 代码、训练产物、交互演示、多种子研究、失败诊断和投递材料已经在本地形成。
- 2026-10-16 经用户授权，以 MIT 许可发布到 `liangqianxing/embodied-pickplace-lab`。公开发布不是外部采用、独立复现或学术影响的证据。
- 发布包保留原始数据、33 个权重、冻结源码、结果与校验清单；不包含本机虚拟环境、运行日志或凭据。
- Panda 标准机械臂任务的本地复验已完成，并且没有支持相同 EMA 在 50 ms 下的收益。它仍不是独立第三方验证。

## 发布前的门槛

1. 完成外部任务复验，并区分标准任务指标和自定义额外指标。
2. 已确认当前登录账号 `liangqianxing`、仓库名 `embodied-pickplace-lab`、公开属性及 MIT 许可；上游 issue 提交不包含在本次仓库发布中。
3. 复查分享包不包含虚拟环境、个人密钥、机器目录信息或第三方未经授权的数据；依赖模型资产通过上游包安装，不把整个环境打包。
4. 运行依赖安装、自动测试、数据/权重校验与实验重放；在另一干净环境复验后再提高“可复现”的声明强度。
5. 将主结论、负结果、失败视频、协议与原始结果一起发布，避免只发成功率最好的截图。

## 应追踪的外部证据

- 一位真实外部用户按说明完成安装或复跑，以及对应 issue / 反馈。
- 接受的代码贡献、错误报告或实验建议。
- 公开技术文章的真实阅读与讨论，不使用购买、刷量或虚构数据。
- 研究实习投递中收到的具体技术反馈，不把未答复或发送邮件数当“学术影响”。

公开仓库和技术文章是传播动作，不自动等于影响力。可以先把目标设为获得可追溯的独立复跑和技术反馈，但不能承诺一定获得，也不能在发生之前写进简历。

## 可用的发布说明草稿

这个项目从一个 MuJoCo 抓取搬运闭环出发，记录了低数据模仿学习在部署条件变化时的失败。我们保留了 15,000 回合、多训练种子的完整消融与负结果：相对坐标和噪声增强没有改善预先指定的平均扰动指标，而一组干净条件下成功率 100% 的策略在 50 ms 指令延迟下平均降至 49.6%。仓库提供逐回合数据、失败重放、源代码快照和验证工具。当前证据仅来自状态输入仿真任务，欢迎独立复现和指出问题。

Panda 本地复验已完成：50 ms 下原始策略为 67.2%，EMA 为 60.8%，未支持迁移收益。公开介绍必须同时保留这一负结果；不得宣称已有独立复现或社区采用。
